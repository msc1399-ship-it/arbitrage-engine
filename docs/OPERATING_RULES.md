# Reglas operativas — 1.000 € / 90 días

## Fase 1 — Paper trading
Duración: 14 días.
Capital real utilizado: 0 €.

Una oportunidad se registra incluso si luego resulta ser un error. No se eliminan falsos positivos.

## Compra virtual individual
Requisitos mínimos:
- precio de compra <= 300 €
- beneficio neto esperado >= 50 €
- ROI neto esperado >= 20%
- >= 5 ventas/6m cuando exista dato
- confianza >= 70%

## Lotes
Requisitos iniciales:
- beneficio esperado >= 75 €
- ROI esperado >= 25%
- aplicar factor de completitud por set
- penalizar sets sin caja/manual/piezas dudosas

## Capital real tras validación
- máximo 25% del capital disponible por operación
- nunca más de 3 posiciones simultáneas en la primera fase real
- no reinvertir beneficio no realizado

## Métricas del experimento
- oportunidades detectadas
- PAPER_BUY emitidos
- falsos positivos
- beneficio esperado vs observado
- ROI esperado vs observado
- días hasta desaparición/venta
- capital inmovilizado
- precisión de identificación
- precisión de valoración
